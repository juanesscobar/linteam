# LINTEAM — Guía rápida para el equipo

LINTEAM es el espacio de trabajo de Lin Group para registrar, asignar y seguir tareas.

## Ingresar por primera vez

1. Recibí del administrador el **código de empresa** y tu **token de invitación**.
2. Abrí `https://linteam.online/join`.
3. Completá tu nombre, correo, contraseña y los datos recibidos.
4. Luego ingresá normalmente en `https://linteam.online/login`.

> No compartas tu contraseña ni el token de invitación. El token se usa una sola vez.

## Crear una tarea o ticket

1. Presioná **Crear**.
2. Escribí un título claro y una breve descripción.
3. Elegí prioridad y fecha límite si corresponde.
4. Podés dejarla sin responsables o seleccionar a una o varias personas.
5. Presioná **Crear tarea**.

## Asignar o autoasignarse

1. Abrí la tarea con **Ver detalle** o haciendo clic en su tarjeta del Pipeline.
2. En **Responsables**, marcá las personas que participarán. Podés marcarte a vos mismo.
3. Presioná **Guardar cambios**.

La primera persona seleccionada queda como responsable principal. Una tarea puede tener varios responsables.

## Actualizar el estado

Desde el detalle de la tarea seleccioná el estado y presioná **Guardar cambios**. También puede actualizarse desde el Pipeline.

- **Nuevo:** recién creado.
- **Asignado:** ya tiene responsable.
- **En progreso:** se está trabajando.
- **En espera:** falta una respuesta o condición.
- **Bloqueado:** no puede avanzar por un impedimento; indicá el motivo al equipo.
- **En revisión:** está listo para revisar.
- **Completado:** trabajo terminado.

## Vistas principales

- **Inicio:** resumen personal y tareas que requieren atención.
- **Mi trabajo:** tareas creadas por vos o asignadas a vos.
- **Pipeline:** visión compartida de todas las tareas del equipo.
- **Trabajo:** administración de tareas creadas; permite archivarlas sin perder el historial.

## Buenas prácticas

- Usá títulos breves y descriptivos.
- Asigná responsables apenas sepas quiénes participarán.
- Actualizá el estado cuando haya avances o bloqueos.
- No uses tareas para compartir contraseñas, tokens u otra información sensible.
